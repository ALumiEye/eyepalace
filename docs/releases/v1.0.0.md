## Eye Palace v1.0.0 — Thủ Thành

Bản phát hành đầu tiên của Eye Palace.

**Chơi trên trình duyệt:** https://alumieye.github.io/eyepalace/ — chạy qua http nên cài được như ứng dụng và chơi offline.
**Chơi offline:** tải `eyepalace.html` bên dưới rồi bấm đúp để mở. Cả game nằm trong một file, không cần mạng hay cài đặt.

### Nội dung
- 8 bản đồ cố định, bản đồ ngẫu nhiên theo mã và trình vẽ bản đồ có thể chia sẻ.
- 3 độ khó, các thử thách cộng điểm, thử thách đổi mỗi ngày, chế độ vô tận sau đợt 30.
- 8 loại tháp, 2 kỹ năng, nhạc chiến đấu thích ứng theo mức nguy hiểm.
- Thành tựu, kỷ lục, ván lưu; xuất/nhập dữ liệu bằng file JSON.
- Phiên bản đang chạy hiện ở cuối menu chính.

### Lưu ý
- Dữ liệu chơi lưu trong trình duyệt; bản web và bản một file dùng kho lưu riêng.
- `SHA256SUMS.txt` dùng để kiểm tra file tải về.
- **Source code (zip/tar.gz)** là mã nguồn, không phải bản chơi offline.
